# Agent Instructions

This file is the home for project-specific guidance for coding agents working on Global Calculator.

## Project Context

- Global Calculator is a Next.js App Router application written in TypeScript.
- Styling uses Tailwind CSS and Shadcn/UI components.
- The product focuses on accurate, accessible calculators across finance, business, health, math, travel, and utility categories.

## Working Guidelines

- Prefer existing project patterns before introducing new abstractions.
- Keep changes focused on the requested calculator, page, or component.
- Maintain accessible labels, keyboard-friendly controls, and responsive layouts.
- Validate calculator formulas carefully and keep units/currency behavior explicit.
- Run the relevant lint, type-check, or build command after meaningful code changes when available.
